# Three Question Quiz

Runs a three-question multiple-choice quiz and reports a score.

## Build and run

```sh
gcc -std=c11 -Wall -Wextra -pedantic main.c -o app
./app
```

## Features

- Reads user input and checks that values are in range.
- Prints a clear result using standard C I/O.
- Keeps the program in one source file for easy study.

## Learning goals

Practice functions, conditions, loops, numeric input, and formatted output in C. Extend the program with saved records or a menu as a next step.
